The console

Commands

Open the console anywhere with ~ (or `). Every command is prefixed pray. Up and down walk your history.

Hers

pray skip_stage
In Devotion, Multitap or OT12: skip the current line or round, but still count it as progress. The server does the counting and checks again that it is you.
e.g. pray skip_stage
pray launch admin | commands
Open the admin panel, or this page. The same command anyone uses to launch a game; these two targets are yours alone, and appear in pray launch list only for you.
e.g. pray launch admin

Anyone

pray login
Open the sign-in page. Only you have an account; everyone else is a guest and never needs this. Nothing on the site links to it.
pray launch <game | page>
Jump to a game or page. Games: devotion, multitap, summary, skillcheck, ot12, snake, deathroll, elysium, chess, wheel, lottery, parse. Pages: dashboard, games. Old names still work (t9, slots, dummyparse, tree, penance). The ported games open as sections of the dashboard now, so these land on the right panel rather than a page.
e.g. pray launch snake
pray launch list
Print every launch target with a word on each.
pray reload
Reload the current page.
pray quit
Close the tab, if the browser allows it.
pray
On its own, a small acknowledgement.

Hand-maintained: when a command is added to public/console.js, add it here too.
