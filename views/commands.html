Console commands

Open the console anywhere with ~ (or `). Every command is prefixed pray. Up/down arrows walk your history. Admin-only commands are marked.

Admin

pray points <username> <+n|-n>
Add or remove points. A signed number: +5 grants, -1 removes.
e.g. pray points alice +5   pray points alice -1
pray set_points <username> <value>
Set an account's points to an exact value.
e.g. pray set_points alice 100
pray delete_account <username>
Permanently delete an account. Cannot be undone.
e.g. pray delete_account alice
pray skip_stage
In Penance, Devotion or Multitap: skip the current line, but still count it as progress.
e.g. pray skip_stage
pray manage
Open account management: create visitor/disciple accounts and review applications.
pray open <username>
Open an account's profile.
e.g. pray open alice

Anyone

pray launch <game|page>
Jump to a game or page: snake, penance, devotion, wheel, deathroll, elysium, chess, parse, skillcheck, summary, dashboard, profile, games.
e.g. pray launch snake
pray reload
Reload the current page.
pray quit
Close the tab (if the browser allows it).
pray
On its own, a small acknowledgement.
This page is hand-maintained: when a new command is added to public/console.js, add it here too.
