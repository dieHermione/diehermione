Console commands

Open the console anywhere with ~ (or `). Every command is prefixed pray. Up/down arrows walk your history. Admin-only commands are marked.

Hers

pray skip_stage
In Devotion, Multitap or OT12: skip the current line/round, but still count it as progress.
e.g. pray skip_stage
pray launch admin | commands
Open the admin panel, or this page. Same command anyone uses to launch a game; these two targets are hers alone, and only show up in pray launch list for her.
e.g. pray launch admin

Anyone

pray login
Open the sign-in page. Only Hermione has an account; everyone else is a guest and never needs this. Nothing on the site links to it.
pray launch <game|page>
Jump to a game or page. Games: snake, devotion, multitap, summary, skillcheck, ot12, deathroll, parse, elysium, chess, wheel, lottery. Pages: dashboard, games. Old names still work (t9, slots, dummyparse, tree, penance).
e.g. pray launch snake
pray launch list
Print every launch target with a word on each.
pray reload
Reload the current page.
pray quit
Close the tab (if the browser allows it).
pray
On its own, a small acknowledgement.
This page is hand-maintained: when a new command is added to public/console.js, add it here too.
